## ML-ZoomCamp-Capstone-project-2

# Student Exam Performance Prediction

This repository features a comprehensive dataset designed to analyze and predict student academic outcomes. It contains **20,000 records** capturing a wide array of academic behaviors, study habits, lifestyle routines, and environmental conditions.

### Dataset Overview
The data reflects the complex interplay between a student’s daily life and their learning environment. Key features include:

* **Academic Metrics:** Daily study hours and class attendance percentage.
* **Lifestyle Factors:** Sleep duration, sleep quality, and physical activity.
* **Environment & Resources:** Internet availability, institutional facility ratings, and study methods (e.g., coaching or self-study).
* **Assessment Context:** Exam difficulty levels.

### Logical Correlations
The dataset is synthetically generated to mirror realistic academic patterns:

* **Positive Drivers:** Consistent attendance, higher study hours, and quality sleep are strongly correlated with better results.
* **Support Systems:** Access to coaching and mixed study methods typically enhance performance.
* **Constraints:** Limited internet access or poor facilities act as significant disadvantages.
* **Difficulty Scaling:** Exam scores are logically adjusted based on paper difficulty.

### Project Objective
The primary goal of this project is to develop a **predictive model** to estimate the `exam_score` (0–100) based on the provided features. By applying regression and other techniques, we aim to identify which variables most significantly impact a student's success.
